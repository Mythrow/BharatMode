# Bharat Mode — brand kit (palette decision pending)

## Identity
Name: **Bharat Mode**. Brand meaning: a mindset of inventing, building, improving and discovering. Tagline: **Big Ideas. Real Progress.** Supporting signature: **Mode: ON.**

Voice: calm, optimistic, grounded, curious. No TV-news red tickers, loud alert sounds, or oversized flag graphics. Keep first 3 seconds for the story hook.

## Typography and layout
Provisional font stack: Inter → Aptos → Segoe UI → sans-serif. 1080×1920 px; clear 78–80px side margins; use compact upper labels, bold but readable headings, soft backgrounds, animated metrics and restrained motion.
