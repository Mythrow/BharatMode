# Approved owner artwork

These are the **only current approved** Bharat Mode badge and avatar assets. They were supplied directly by the channel owner and committed without redrawing, changing colors or font substitution.

- [`bharat-mode-badge.svg`](bharat-mode-badge.svg) — primary horizontal badge.
- [`bharat-mode-avatar.svg`](bharat-mode-avatar.svg) — YouTube profile avatar / small icon.

Both are self-contained SVGs with vector paths, no external fonts or remote images.

**Do not modify either file without explicit design approval.** Run `npm run logo:check` to catch accidental changes. Read `docs/LOGO_DIRECTION.md` for exact usage and approved SHA-256 hashes. The general video palette lives separately in `src/brand.js`.
