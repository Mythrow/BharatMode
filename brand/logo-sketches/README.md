# Bharat Mode early vector sketches

These **are not approved final logos**. They are light, editable SVG shape studies for:
- `mode-switch.svg` — activation/ON concept
- `bm-monogram.svg` — letterform/icon concept
- `forward-mark.svg` — progress/innovation abstract

Official colors: `#E8752E`, `#FFF7EB`, `#117A7A`, `#283039`, `#0B1018`.

Use them as discussion tools. A final production logo must be reviewed and drawn as a deliberate vector mark, tested at 48px in a YouTube circular profile crop, and documented in `docs/LOGO_DIRECTION.md`.
