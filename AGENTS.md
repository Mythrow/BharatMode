- Native 1080×1920/60fps or better; story-specific open-canvas motion; real acoustic alignment; preserve V6 chrome and later refinements. Preview prototypes and old bridge scripts are not production renderers.

- **GitHub documentation is authoritative.** When the owner asks to update/save/document a rule, decision, correction or handoff, edit the appropriate canonical file directly in `Mythrow/BharatMode` on GitHub. Commit the change and re-fetch the committed file to verify it before reporting completion; include the commit link. Local Markdown notes, source-package README files, chat summaries and Library artifacts are not substitutes for a GitHub documentation update. If GitHub access genuinely fails, report the actual error and the outstanding update explicitly; never claim completion or silently substitute a local note. Keep episode-specific evidence separate from permanent standards.

Do not infer publication approval from creative acceptance, upload or a scheduled date. Never invent evidence, dates, URLs or owner approvals.
